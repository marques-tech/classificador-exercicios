# Coleta de dados meteorológicos com API

Atividade prática da disciplina de Ciência de Dados, UNIFEI.

Coleta dados de previsão do tempo de 3 cidades (Pouso Alegre, Itajubá e Belo Horizonte) usando a API Open-Meteo, organiza com pandas e gera gráficos com matplotlib.

Tecnologias: Python, requests, pandas, matplotlib.
